PROJECT AURA v2 — PERSONAL DESKTOP WIDGET

What's new:
- Larger desktop widget with a closer red/pink neon look
- Floating clock/date and animated ring
- Drag to reposition
- Right-click menu: toggle clock/ring, change accent, reset position, hide/show, quit
- Hidden launcher so CMD doesn't stay visible

Run:
1. Extract the ZIP.
2. Double-click Start_AURA.vbs.

If Windows blocks the VBS file, right-click > Open, or use Run_AURA.bat (shows CMD).

This is still a prototype:
- Ring has ambient animation; it is not yet connected to live system audio.
- Track title/media controls are not included yet.
- Set your anime wallpaper separately in Windows Personalization.
